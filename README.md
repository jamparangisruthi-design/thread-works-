# Sruthi Threads & Designs

> *"Where Every Thread Tells a Story."*

A bespoke Indian luxury couture boutique website showcasing handcrafted designer blouses, authentic Maggam and Aari embroidery, heritage silk sarees, and handcrafted silk thread bangles.

---

## 🌸 Collections
- **Curated Sarees**: Handpicked Kanchipuram bridal pattu, Banarasi brocades, organza, tussar silk, and tissue weaves.
- **Designer Blouses**: Peacock motifs, Swarna temple borders, 3D floral cutwork, lotus petal necklines, and royal velvet zardozi.
- **Handcrafted Bangles**: Bridal chooda sets, antique zari kadas, pearl and kundan latkans, and personalized name bangles.
- **Thread & Maggam Embroidery**: Authentic resham needlework, bridal monograms, and custom embroidery.
- **The Bridal Edit**: Grand wedding ensembles, trousseau creations, and couture lehengas.

---

## 🚀 Getting Started

### Local Development Server
To preview the website locally:
```bash
# Using Node.js
node server.js
```
Then visit [http://localhost:5500](http://localhost:5500) in your browser.
